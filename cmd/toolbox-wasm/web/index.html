    文档校验

    按 GB/T 33190 与 OFD Schema 检查包结构、XML、引用与签名摘要。

    载入 OFD 后点击「开始校验」。

    结构分析

    文档结构、资源统计与签名详情。

    载入 OFD 后点击「开始分析」。

    发票抽取

    从增值税电子发票 OFD 读取结构化发票信息。

    载入发票 OFD 后点击「开始抽取」。

    水印

    添加、替换或删除页面水印注解。

    载入 OFD 后点击「添加水印」。

    文档合并

    把两个以上 OFD 合并：整体合并产出多文档包，拼页产出单文档。

    把两个以上 OFD 加入文件队列后点击「开始合并」。

    长期保存处理

    按 GB/T 42133 第 6 章处理。先预检，确认改动后再执行。

    载入 OFD 后点击「开始预检」。

    就绪
    内存占用

    线性内存只会增长，回收只会让空闲页可复用。数值偏大不等于泄漏。

    字体

    浏览器里没有系统字体，文档声明的字体（如宋体、黑体）如果 没有内嵌文件就画不出来，预览会是空白或方块。注册一份中文字体即可让所有 缺字体的文字正常显示。

    关于 OFD 工具箱

    全部处理在本机浏览器内完成，文件不会上传到任何服务器。

    基于 zc310/ofd 构建的 WebAssembly 引擎，支持 OFD 与 PDF 互转、图像与文本导出、文档校验、 结构分析、发票抽取、水印、合并与长期保存处理。

    本工具不保证解析或转换结果适用于特定业务、法律与合规场景。 电子签名的有效性需要用 OFD 阅读器另行核验。

    纯浏览器环境无法运行 LibreOffice、Chrome 与 Tesseract， 因此 Office 文档与 HTML 转换、OCR 不在支持范围内。
